# Combinar Etiquetas

A small web application that makes it easier to print shipping labels from **Vinted**.

When selling several products on Vinted, labels can come from different shipping companies and have different formats. This application combines multiple labels into a single **A4 page**, making them easier to print and organize.

## 🚀 Live Demo

https://combinaretiquetas.onrender.com

## ✨ Features

* Combine multiple Vinted shipping labels.
* Support labels from different shipping companies.
* Automatically arrange labels on an A4 page.
* Generate a page ready to print.
* Simple and easy-to-use interface.
